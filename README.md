# Skate4 Launcher Setup

Simple native Windows installer for `Skate4Laucnher.exe`.

## Before You Install

1. Download the ZIP.
2. **Extract the ZIP first.**
3. Move the extracted `Skate4LauncherSetup.exe` somewhere safe, such as:
   - `Documents\Skate4 Setup\`
   - `Desktop\Skate4 Setup\`
   - another folder you will not accidentally delete
4. Do **not** run the installer directly from inside the ZIP.
5. Run `Skate4LauncherSetup.exe`.

## Changes

- Installs `Skate4Laucnher.exe` directly onto your Desktop.
- Uses Windows' actual Desktop known-folder path.
- Safely handles redirected or OneDrive Desktop folders.
- Tests Desktop write access before installation.
- Shows clear errors instead of silently failing.
- Verifies the installed launcher after copying.
- Refreshes Windows Explorer so the icon appears immediately.
- Keeps the embedded Skate4 application icon.
- Includes a native loading spinner.
- Includes a real installation progress bar.
- ZIP contains only `Skate4LauncherSetup.exe`.

## Install

1. Extract the ZIP.
2. Store the setup EXE somewhere safe.
3. Open `Skate4LauncherSetup.exe`.
4. Follow the installer.
5. `Skate4Laucnher.exe` will be installed directly to your Desktop.

## Platform

Windows 10 / 11 x64
