Simple native Windows installer for the current **Skate4 Launcher**.

## What It Does

- Installs the exact current `Skate4Laucnher.exe` directly onto your Desktop.
- Replaces the existing Desktop launcher instead of creating duplicates.
- Uses Windows' actual Desktop location.
- Supports normal, redirected, and OneDrive Desktop folders.
- Verifies the launcher after installation.
- Keeps the Skate4 application icon embedded.
- Does not copy files from the folder where Setup is launched.
- Does not scan, copy, mirror, or duplicate files from your Skate4 game root.
- Does not modify your mods, projects, game files, or Steam sign-in data.
- ZIP contains only `Skate4LauncherSetup.exe`.

## Install

1. Download the ZIP.
2. **Extract the ZIP first.**
3. Put `Skate4LauncherSetup.exe` somewhere safe.
4. Do not run Setup directly from inside the ZIP.
5. Run `Skate4LauncherSetup.exe`.
6. Follow the installer.
7. `Skate4Laucnher.exe` will be installed directly onto your Desktop.

## Important — Keep Your Settings File

After installation, you must keep:

**ReSkateLauncher.settings.json**

on your Desktop beside:

**Skate4Laucnher.exe**

Your Desktop should contain:

- `Skate4Laucnher.exe`
- `ReSkateLauncher.settings.json`

**Do not delete, move, or rename `ReSkateLauncher.settings.json`.**

The launcher uses this file to keep your launcher preferences and saved settings between launches.

Removing the settings file may cause the launcher to create a fresh configuration and reset some options.

## Desktop Setup

📁 **Desktop**

- 🎮 `Skate4Laucnher.exe`
- ⚙️ `ReSkateLauncher.settings.json`

Keep both files together.

## Setup Does Not Touch

The installer does not copy, replace, move, or modify:

- `Skate.exe`
- `ReSkate.dll`
- `Mods`
- `Custom`
- `scripts`
- Steam / QR sign-in data
- Skate4 game-root files

## Important

`Skate4LauncherSetup.exe` is a **Desktop-only launcher installer**.

It installs one launcher file to your Desktop.

It does **not** install or duplicate files from your game directory.
